# My First Web Project 

Welcome to my very first web development and version control project! As a first-year **Computer Science Engineering (Cybersecurity)** student, this project marks the beginning of my journey into software development, web structures, and practicing Git workflows.

---

## 📌 Project Overview

This project is a simple webpage built using semantic HTML5 to practice page structuring and version control using Git and GitHub.

* **Project Name:** My-First-Project
* **Developer:** 1st Year CSE (Cybersecurity) Student
* **Focus Areas:** Web Basics, Git Version Control, Terminal Usage

---

## 🛠️ Tech Stack & Tools

* **Markup Language:** HTML5
* **Version Control:** Git & GitHub
* **Code Editor:** Visual Studio Code (VS Code)
* **Terminal:** PowerShell / Integrated Terminal

---

## 💡 Key Learnings & Concepts

* **Semantic HTML:** Using structure tags (`<doctype>`, `<html>`, `<head>`, `<body>`, `<header>`, `<main>`) and text elements (`<h1>`, `<p>`).
* **Git Operations:** Initializing repositories, tracking files, staging changes, committing updates (`git commit`), and pushing to GitHub (`git push`).
* **Developer Environment:** Configuring VS Code extensions, working with local file paths, and browser rendering.
